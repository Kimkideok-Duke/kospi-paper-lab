# 모의투자 v2 운영 기준

2026-11-25 사용자 요청으로 다음 기능을 국내·미국장에 함께 적용한다: 비용 반영, 시장 대비 성과, 위험·매매 통계, 호가 기반 모의 체결, 주가·환율 손익 분리, 운영 알림, 전략 버전·일별 기록. 추가 요청에 따라 **신규 분석은 10분, 보유 감시는 1분**이다. 앞서 준비한 실거래 소스는 계속 비활성이다.

## 기록 보존

기존 SQLite의 국내장·미국장 상태 JSON에 새 정보를 추가한다. 기존 현금·보유 종목·거래·분석 기록을 초기화하거나 과거 체결 가격·비용을 재작성하지 않는다. `paper-v2-10m` 적용 시각·설정·평가자산을 새 버전으로 기록한다. 버전 이전의 거래는 화면에서 ‘이전 모의 방식’으로 표시한다.

새 모듈은 `server/paper-model.mjs`, `server/paper-analytics.mjs`, `server/monitor-batch.mjs`다. 비용과 체결 설정 변경은 인증·동일 출처 검사를 거치는 `/api/model` 및 `/api/us/model`에서만 허용한다. 설정을 변경하면 현재 미체결 주문은 취소하고 새 버전으로 이후 주문을 생성한다.

## 시간과 감시

- 국내: 09:03 첫 분석, 09:10부터 10분 간격. 실제 거래소 정규장 연속매매 중에만 신규 모의 체결하며 16:00은 평가 전용이다.
- 미국: 실제 개장 +3분 첫 분석, 이후 개장 +10분, +20분, … 및 실제 마감 평가. 정상 장이면 동부 09:33, 09:40, 09:50, …, 15:50 분석 및 16:00 평가다. DST·휴장·조기 폐장을 반영한다.
- 예정 분석 시각부터 3분 이내 실행하며, 놓친 회차를 소급 체결하지 않는다. 예정 회차 누락은 운영 알림에 남긴다.
- 독립 서버 타이머가 보유 종목과 미체결 주문을 1분 간격으로 확인한다. **감시에서는 새 매수 신호를 찾지 않고**, 기존 매수 주문의 잔량 체결 및 손절·익절·기존 매도 주문 처리를 한다.
- 1분 감시는 연속 감시가 아니다. 급변·PC 종료·통신 장애·호가 부족 시 손절 기준 가격이나 손실률이 보장되지 않는다. 마감 평가에서는 거래하지 않는다.

## 기본 비용과 체결 가정

| 항목 | 국내 | 미국 |
| --- | --- | --- |
| 매매 수수료 | 0.015% | 0.1% |
| 주식 매도 거래세 | 0.20% | 0% |
| ETF 거래세 | 0% | 0% |
| 환전 스프레드 | 0% | 매 거래 원화 금액의 0.1% (모의 가정) |
| 호가 잔량 사용 | 가격 단계별 표시 잔량의 10% | 같음 |
| 허용 가격 범위 | 주문 생성 시 최근 체결가 대비 ±0.2% | 같음 |
| 미체결 유효 시간 | 최대 300초, 정규장 종료 시 만료 | 같음 |

기본 수수료·국내 거래세는 아래 공식 자료를 참고한 모의 기본값이며 개인 우대·프로모션·소액 면제는 반영하지 않는다. 설정에서 수정할 수 있다. 미국 SEC/FINRA 제비용, 배당세, 국내 ETF 보유기간 과세·분배금 등은 포함하지 않는다. 미국 환전 스프레드는 API가 보장한 실제 거래 비용이 아닌 조정 가능한 가정이다.

최신 체결가(90초 이내)와 호가(30초 이내)를 함께 요구한다. 매수는 낮은 매도 호가, 매도는 높은 매수 호가부터 최대 5단계를 사용한다. 표시 잔량은 실제 체결을 보장하지 않으므로 일부만 사용한다. 동일 종목·방향·가격·호가 시각의 잔량 사용량을 보관해 같은 스냅샷을 반복 소비하지 않는다. 가격 범위를 벗어나거나 호가가 없으면 미체결, 일부만 가능하면 부분 체결, 시간이 지나면 잔량 만료로 기록한다. 이는 거래소의 실제 대기 순번·숨은 유동성·지연을 재현하는 모델은 아니다.

현금 차감액에는 매수 수수료·환전 비용을 더하고, 매도 입금액에서는 수수료·해당 거래세·환전 비용을 뺀다. 매수·매도 주문과 체결을 분리해 보관하고, 대기 매수 주문의 예상 금액과 종목 슬롯을 확보한다. 비용과 슬리피지는 실제 사용한 모의 호가 가격 및 비용 항목으로 기록한다. **호가와 기준가의 차이인 슬리피지는 이미 체결 가격에 반영되어 있으므로 현금에서 다시 차감하지 않는다.**

## 성과와 정보

- 순손익: 실제 모의 현금·보유 평가 기준으로 수수료·거래세·환전 비용이 반영된다. ‘명시 비용 차감 전 참고손익’은 누적 명시 비용을 더한 참고치이며, 비용이 없었다면 달라졌을 보유 수량·후속 전략을 재계산한 백테스트는 아니다.
- 위험: 관측 평가금액의 최대 낙폭, 매도 체결별 승률·평균 이익·평균 손실·이익 합/손실 합·최대 연속 손실·표본 수. 부분 체결도 각각 한 표본이다. 감시 사이의 장중 최저값은 알 수 없다.
- 비교: 국내 KOSPI·KODEX 200, 미국 SPY·QQQ. 업데이트 이후 유효한 정규장 시세가 처음 관측된 시점부터 전략과 기준의 같은 기간 수익률을 비교한다. 미국 기준도 환율을 반영한 원화 가격수익률이다. 비교 그래프는 배당과 기준 자체의 매매 비용을 제외하며, 과거 누락 시세를 만들지 않는다.
- 미국 손익 분해: 매도 체결 및 보유 평가의 주가 기여 + 환율 기여 + 비용·반올림 잔차 = 분석 대상 원화 손익. 이전 방식 실현손익은 별도로 표시한다.
- 미국 양도세: 해당 모의계좌의 연간 실현손익만 대상으로 공제 250만원·22%의 단순 추정액을 별도 표시한다. 모의 현금에서 다시 빼지 않는다. 다른 계좌, 실제 결제일·환율·세금신고 자료를 합산한 세무 계산이 아니다.
- 일별 기록: 새 모델 적용 이후 관측 자산의 시작·고가·저가·마지막 값과 전일 관측 대비 손익. 전략 버전별 적용 시각·평가 기준·체결 수·실현손익·기간 평가 수익률도 함께 보관한다.

## 운영 알림

예정 분석 누락, API 오류, 오래된 시세·호가, 1분 감시 체결은 각 시장 상태에 최근 100건까지 저장한다. `/api/health`는 서버 응답과 감시 타이머 최근 활동을 제공한다. 사이트는 서버 연결 실패와 감시 지연을 표시한다.

‘브라우저 알림 켜기’를 직접 선택해 브라우저 권한을 허용하면, **사이트가 열려 있고 브라우저가 실행되는 동안** 새 운영 알림·연결 실패를 데스크톱 알림으로 표시한다. 이메일·문자·외부 푸시 서비스는 연결하지 않는다. 서버나 브라우저가 모두 꺼진 상태를 별도 외부 서비스 없이 실시간 통지할 수는 없다. 재시작 후 놓친 회차를 기록한다.

## 사전 지정가 주문 (2026-11-26)

국내·미국장 모두 일반 진입은 분석 기준가보다 설정된 가격 여유(기본 0.20%) 낮은 가격에 지정가 매수 주문을 두고 최대 15분 기다린다. 후보의 허용 가격 범위 안에서만 주문한다. 최근 분봉 상승률 1% 이상이며 뉴스 주의가 없는 후보 또는 장중 뉴스·공시 추가 분석은 기존 즉시 체결 우선 지정가를 사용한다. 가격 여유는 체결 설정의 limitBps를 함께 사용한다.

보유 종목은 다음 1분 감시부터 평균 매수가 대비 +5%의 사전 매도 주문을 당일 정규장 종료까지 유지한다. 추가 부분 매수로 수량·평균가가 달라지면 주문을 갱신한다. 손절·추세 약화·뉴스/공시 보호 매도는 이 주문을 취소한 뒤 우선 처리한다. 매수 주문은 악재 차단, 기준가 대비 -1.5% 하락 또는 +1% 상승 시 잔량을 취소한다. 미체결·부분 체결·예약 현금과 종목 슬롯은 원장에 보관한다. 다른 매수 주문의 예약금도 체결 시 보호하며 미국은 당시 환율을 다시 적용한다.

체결은 감시 시점에 관측한 최신 반대 호가가 지정가 이내이며 사용 가능한 잔량이 있을 때만 인정한다. 감시 사이에 목표가를 찍었더라도 그 사실만으로 체결을 생성하지 않는다. 거래소 호가 단위·대기 순번을 완전히 재현하지 않는 내부 모의 주문이며 실제 증권사에 전송하지 않는다. 주문 목록에는 방식·지정가·만료 시각을 표시한다. 새 버전은 기존 거래·현금·보유분을 보존하고 이전 대기 매수만 취소한다.

## 보유 감시 주기 변경 (2026-11-26)

사용자의 명시적 적용 요청으로 국내·미국장 보유 종목·기존 미체결 주문 감시는 5초 간격으로 변경했다. 신규 종목 탐색은 10분 간격, 뉴스 2분·공시 1분·공식 발표 5분·추가 분석 최대 2분 1회는 유지한다. 감시 자체는 신규 매수 신호를 만들지 않는다.

타이머는 실행이 끝나야 다음 5초 경계에 예약하므로 겹치거나 놓친 회차를 몰아서 실행하지 않는다. 실행 시간이 길면 실제 간격도 늘어나며, 감시 오류 시 10·20·40·60초로 대기하고 성공하면 5초로 복귀한다. 그룹별 공통 API 대기열·응답 헤더 제한과 429 백오프도 유지한다. 장외·휴장·API 미연결의 유지 관리는 거래일 변경과 개장 시점을 확인하면서 1분 간격으로 제한한다.

빠른 시세·호가는 보유·기존 대기 주문에 집중한다. 매도 완료 종목 복기 시세·벤치마크·KOSPI 추가 조회는 1분 단위다. 평가 일별 고저는 감시 때마다 갱신하며 화면용 자산 추이는 같은 분의 마지막 감시값으로 합쳐 누적 크기를 제한한다. 체결 내역은 전부 보존하고 감시 체결·알림 ID는 5초 구간으로 구분한다. 같은 호가 스냅샷의 잔량 중복 사용 방지는 그대로다. 이전 비용·위험 한도·손절/익절·대기 주문은 이번 변경으로 바꾸거나 취소하지 않는다. `monitorPolicy`와 버전 기록으로 적용 시점을 남긴다.

## 모의 전략 v7

국내·미국 모두 손절 매도 후 같은 종목의 신규 주문을 마지막 손절 체결부터 30분간 보류한다. 최근 분봉 상승률 3% 이상인 후보도 보류한다. 두 값은 캠페인 검증을 위한 초기 가정이다. 손절 지정가 아래에 매수호가가 형성되면 주문 생성 5초 후부터 새로 관측한 유효 호가의 최우선 매수 가격까지 잔량의 한도를 조정한다. 원래 신호 가격을 유지해 가격 차이를 계산하며 호가 잔량 제한을 적용한다.

사용자별 모의 분석 응답의 analytics.entryComparisons에 최근 후보 100개의 결정·기준가·10~12분 뒤 관측 수익률과 방식별 3주 가상 주문을 제공한다. 최대 3,000개를 보관한다. 동일 후보에 즉시 지정가, 눌림 지정가, 3분 간격 분할을 10분간 독립 비교한다. 방식별 quantity는 가상 체결 수량, amount는 현지 통화 체결 대금 합계다. 미체결·부분 체결은 수량으로, 관측 빈도는 bookCount로 확인한다. 기존 조회에서 얻은 호가만 쓰므로 보류 후보는 후속 관측이 적을 수 있다. 수수료·시장 충격을 포함한 순수익 비교에는 추가 자료가 필요하다.
