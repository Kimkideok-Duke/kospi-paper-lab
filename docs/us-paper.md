# 미국장 모의자동매매

2026-11-25 사용자 선택: 기존 사이트에 미국장 탭을 추가해 같은 PC에서 자동 운영한다. 국내장과 별도로 1,000만 원을 시작 원금으로 사용하며 **매 거래 시점 환율로 원화 잔고를 정산**한다. 기간은 미국 현지 거래일 기준 2026-11-25~2026-12-24이며 마지막 거래일 마감 평가까지 운영한다. 마지막 회차의 한국 날짜는 12월 25일일 수 있다.

## 실행과 보관

- 기존 `node scripts/local.mjs`가 두 시장의 배치를 함께 실행한다. `--preview`에서는 모두 끈다.
- `/`는 국내장, `/us`는 미국장, `/us/trades`는 미국장 거래내역이다. `/settings`의 API 연결은 공유한다.
- `campaign.sqlite`의 `campaign`과 `us_campaign` 테이블로 현금·보유 종목·거래·분석 기록을 분리한다. `drizzle/0001_us_campaign.sql`은 새 테이블만 추가하며 기존 기록을 초기화하지 않는다.
- 기존 암호화 키·API 키·액세스 토큰을 공유하고 DB 잠금으로 분석·토큰 갱신을 직렬화한다. 동일 Client ID로 별도 미국장 토큰 발급 인스턴스를 만들지 않는다.
- PC가 켜져 있고 인터넷에 연결되어 있어야 한다. 브라우저를 닫아도 서버 배치는 동작한다.

## 시간 기준

미국 현지 날짜는 `America/New_York`로 계산한다. 실제 개장·폐장은 `GET /api/v1/market-calendar/US?date=YYYY-MM-DD` 응답의 `today.regularMarket`을 따른다. 프리마켓·애프터마켓·데이마켓에서는 거래하지 않는다.

- 첫 회차: 개장 3분 뒤. 이후 개장 10분 뒤부터 10분 간격.
- 일반 장: 미국 동부 09:33, 09:40, 09:50, …, 15:50 분석, 16:00 평가. 겨울에는 한국 23:33 첫 분석, 다음 날 06:00 평가다.
- 마감 회차는 평가만 하고 모의 체결하지 않는다. 조기 폐장은 해당 시각으로 평가를 앞당긴다.
- 휴장일 거래 없음. 다음 회차는 API의 `nextBusinessDay`를 참조한다. 서머타임도 실제 세션 시각으로 처리한다.
- 놓친 회차를 과거 시세로 소급 체결하지 않는다. 자동 회차는 예정 시각부터 3분 이내에만 실행한다.
- 정규장 개장 이후 90초 이내 USD 체결가만 거래에 쓴다. 유효한 환율이 없으면 거래를 저장하지 않는다.

## 대상과 전략

NASDAQ·NYSE·AMEX 상장 목록의 주식·ADR·REIT·ETF 중 **미국 시장 거래대금 상위 100종목에 포함된 대상**의 시세를 분석한다. 순위가 없거나 오래되면 신규 매수는 하지 않고 보유 종목의 시세는 따로 확인한다. 조사 수와 전체 상장 목록 수를 구분해 표시한다.

기존 전략과 같은 동시 5종목, 종목별 비중 상한 없이 가용 현금 내 신규 주문, 직전 분석 추세·분봉 모멘텀·거래대금·호가 간격을 적용한다. 미국 주식의 상·하한가가 `null`임을 반영하고 소수점 USD 가격을 허용한다. 최저 매도·최고 매수 호가를 비교하며 국내장과 미국장 API 요청은 공통 대기열에서 그룹별 공식 한도와 응답 헤더에 맞춰 분산한다. 자세한 정책은 `api-limits.md`를 따른다.

−2.5% 손절·+5% 익절·단기 추세 약화는 **달러 주가 기준**이고 원화 손익에는 환율 변화도 반영한다. 개장 회차에는 이전 미국 거래일 마감부터 당일 개장 전까지 미국 뉴스 피드를 수집한다. 출처가 부족하면 시세 기준을 적용한다. 뉴스 분류는 기존 방식의 규칙 기반 판단이다.

## 원화 정산

`GET /api/v1/exchange-rate?baseCurrency=USD&quoteCurrency=KRW`의 `midRate`를 사용하고 `validFrom`~`validUntil`에 현재 시각이 포함되는지 검증한다. 모의 체결 직전에 시세와 환율을 다시 읽으며 거래마다 달러 가격·수량·원화 금액·적용 환율·환율 시각을 저장한다.

- 매수 차감액: `USD 가격 × 수량 × 당시 USD/KRW`를 원 단위 올림.
- 매도 입금액·평가액: 같은 계산을 원 단위 내림.
- 실현손익: 매도 시 원화 입금액 − 매수 시 원화 차감액.
- 계좌는 원화 현금을 유지하며 달러로 일괄 환전하지 않는다.
- 현재 v2는 수수료·거래세·환전 스프레드와 호가 체결 가격을 반영한다. 상세 가정과 제외 세목은 [v2 기준](paper-v2.md)을 따른다.

비용 반영 전 단순 환율 예: $100에 14주, 환율 1,400원으로 매수하면 196만 원 차감. $106, 환율 1,500원에 매도하면 222만 6천 원 입금, 실현손익 26만 6천 원이다.

## 실거래 비활성 및 검증

이 기능은 시세 조회와 모의 원장만 사용한다. `server/live/`는 import·빌드하지 않으며 실제 주문·취소 API를 호출하지 않는다. 앞서 준비한 실거래 소스의 별도 적용 승인 조건은 그대로 유지한다.

`node --test`로 DST, 한국 날짜 변경, 휴장·조기 폐장, 마감 평가, 환율 정산·반올림, 중복 방지, 실제 주문 API 미호출, 공유 토큰, 국내장 기록 보존을 모의 응답으로 검증한다.

공식 근거: [토스증권 OpenAPI JSON](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json), 2026-11-25 확인 버전 1.2.28; [NYSE 거래 시간·휴장 일정](https://www.nyse.com/trade/hours-calendars).
