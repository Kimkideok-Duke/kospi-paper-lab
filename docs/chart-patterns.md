# 차트패턴 가상 비교

국내장 `/patterns`, 미국장 `/us/patterns`의 **차트패턴 분석** 메뉴에서 사용한다. 실제 주문·모의 주문의 조건이나 일별 전략 보완에 연결하지 않는다. `GET /api/patterns`, `GET /api/us/patterns`는 현재 세션 사용자의 저장 원장만 읽으며 외부 API를 호출하거나 DB를 변경하지 않는다.

## 비교 범위

- 최초 매수부터 잔량 전량 매도까지를 한 묶음으로 계산한다. 부분 매수·매도는 같은 묶음에 포함하며 최초 매수 직전의 신호로 묶음 전체를 유지하거나 회피한다. 진행 중인 보유·매수 기록 없는 매도·수량 불일치·손익 누락·자료 부족은 비교 합계에 포함하지 않는다.
- `avoid-bearish`는 하락 신호가 있으면 회피, `require-bullish`는 상승 신호가 있고 하락 신호가 없을 때 유지한다. 유지 시 저장된 매도 실현손익을 합산하므로 해당 거래의 기존 비용·환율·추가 체결·매도 조건을 보존한다. 회피 시 거래 전체의 가상 순손익은 0원이다. 비용 상세가 없는 이전 거래는 별도로 표시한다.
- 합계의 기존 손익과 가상 손익은 같은 비교 가능 표본이다. 계좌 전체 수익률이나 실행 가능한 포트폴리오 백테스트가 아니다. 회피한 자금의 재투자·새로운 거래·패턴 목표가 청산은 계산하지 않는다. 패턴별 통계는 중복 신호를 포함하므로 합산하면 안 된다.

## 자료와 판별

`server/chart-patterns.mjs`의 순수 함수가 판별·거래 묶음·비교를 수행한다. 8개 돌파 유형(이중바닥/천장, 역머리어깨/머리어깨, 대칭삼각형 상·하방, 하락쐐기 상방/상승쐐기 하방)을 지원한다. 이는 종가 구조를 이용한 명시적 근사 규칙이며 가이드 그림 전체를 인식하거나 통계적 성공률을 제공하는 모델이 아니다.

진입 전 최대 60/120분, 가격 유사 오차 0.4/0.8/1.2%, 가격 20개 이상, 마지막 관측 3분 이내, 최대 공백 3분을 사용한다. 좌우 2개 관측으로 변곡점을 확인하고 마지막 가격의 경계 0.1% 초과 신규 돌파를 요구한다. 이중형 깊이 1% 이상·간격 6개 표본 이상, 머리 1% 이상 돌출, 삼각형/쐐기 고점·저점 각 3개와 폭 20% 이상 축소다. 거래량·선행 추세까지 검증한 완전한 전통 패턴 모델은 아니다. 매개변수를 바꿔 반복 조회해 좋아 보이는 결과를 선택하면 과최적화 위험이 있다.

기존 신규 후보 조회의 1분봉을 재사용하며 추가 API 호출은 없다. 봉 시작 시각+1분이 수신 시각 이전인 종가만 보관하고 진입 이후 자료는 제외한다. 신규 매수 체결 직후 `recordReviewEvidence`에서 거래의 `patternEvidence`로 별도 보관하므로 일별 관측자료 보존 기간이 지나도 유지한다. 당시 후보 봉을 사용하지 못하는 대기 주문 체결은 저장된 진입 전 관측가를 사용하며 부족하면 분석 불가로 남긴다. 원래 가격·금액·이유·손익은 바꾸지 않는다.

기능 추가 이전 거래는 남아 있는 복기 관측가로 사후 재구성하며 그 출처와 당시 수신 시각의 불확실성을 표시한다. 현재 API로 과거 봉을 새로 조회해 당시 알고 있던 자료라고 주장하지 않는다. 미래 가격이나 나중에 수신한 관측가를 진입 판별에 사용하지 않는다. 분석 예시는 화면 전용 생성 자료로 실제 원장에 저장하지 않는다.

검증은 8개 유형의 양방향 판별, 미래 봉·미완성 봉 배제, 자료 공백, 부분 체결 묶음, 비용·환율 보존, 조회 시 원장 불변, 잘못된 조건 거절, 인증·사용자 격리를 포함한다.
