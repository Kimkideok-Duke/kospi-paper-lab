# 2026-11-26 개발 변경 기록

## 거래 차트와 매매 지점

- 거래내역과 최근 거래를 클릭하면 종목 차트와 실제 모의 체결 지점을 팝업으로 표시한다. 같은 매수부터 전량 매도까지의 거래를 함께 확인할 수 있다.
- 겹치는 체결은 5분 단위·매수/매도별 수량 가중 가격으로 묶고 선택한 체결은 별도로 표시한다. 관측하지 못한 구간은 점선으로 구분하며 시세를 생성하지 않는다.
- 사용자 세션의 저장 자료만 조회한다. 팝업 조회에 추가 토스 API 호출은 없다.

## 보유 감시 5초

- 사용자 요청에 따라 국내·미국장 보유 종목과 기존 미체결 주문을 5초 간격으로 감시한다. 신규 종목 분석은 10분 간격을 유지한다.
- 실행 중첩과 밀린 회차의 연속 실행을 막고 오류 시 10~60초로 감속한다. 장외 유지관리와 보조 시세 조회는 1분 간격으로 제한한다.
- 화면 표시용 자산 기록은 분 단위로 관리하되 실제 관측 최대 낙폭은 보존한다. 기존 원장과 주문을 유지하는 감시 정책 전환을 기록한다.
- 공식 API 가이드의 그룹별 한도를 문서화했다. 모든 요청은 기존 공통 대기열을 거친다.

## 전체 평가 대상 종목의 종가 별도 확인

- 당일 거래 종목과 마감 보유 종목 전체를 제한 없이 확인한다. 이는 상장 종목 전체 목록이 아닌 해당 모의계좌의 평가 대상 전 종목이다.
- 국내는 사용자가 선택한 토스 KRX·NXT 통합 일봉 종가를 시간외장 종료 1분 후부터 조회한다. 미국은 정규장 공식 일봉 종가를 사용한다.
- 거래일·통화·가격을 검증하고 실패한 종목만 재시도한다. 부분 실패는 완료로 표시하지 않는다. 과거 거래일도 장 일정을 조회해 보완한다.
- 복기에 확인 수, 종목별 종가·확인 시각과 대기/재조회 상태를 표시한다. 원본 보고서를 보존하고 종가 평가 결과를 별도로 반영한다. 환율이나 원장 근거가 부족하면 그 한계를 명시한다.

## 검증과 운영 반영

- 전체 자동 테스트 99개 통과. 종가 확정 시각, 35종목 분할 조회, 재시도, 과거 날짜, 환율 부족, 원본 보존, 감시 중첩/오류 감속 및 사용자 격리를 확인했다.
- 빌드와 문법 검사, Git 공백 검사를 통과했다. SQLite 온라인 백업 후 로컬 서버를 재시작했다.
- 실제 복기 화면에서 전일 대상 전 종목의 종가 확인 완료와 당일 시간외 마감 대기를 확인했다. 당일 통합 종가 확정 이후의 결과는 아직 확인 전이다.
- 실거래 준비 모듈은 연결하지 않았다. 공개 기록에는 키·DB·개인 거래 자료를 포함하지 않는다.

## 이후 변경 기록 규칙

- 소스 수정마다 변경 내용과 검증 결과를 이 디렉터리에 기록하고 함께 커밋·일반 push한다.
- 한국시간 매일 00:05 예약 작업이 전날 소스 변경 커밋을 확인해 개발블로그와 목록을 갱신한다. 문서만 바뀌었거나 소스 변경이 없는 날은 새 글을 만들지 않는다.

## 종목별 복기와 판단 툴팁

- 체결별 반복 복기를 종목별 하루 종합 복기로 변경했다. 매수·매도 판단, 실현손익·명시 비용, 사후 관측에 근거한 가격 비교와 한계를 정리한다. 과거 저장 보고서도 읽기 시 집계하며 원본·전략을 보존한다.
- 복기에서 하루 전체 매매 차트를 열 수 있고, 표식에 마우스를 올리면 판단 이유를 툴팁으로 표시한다. 겹친 부분 체결의 판단은 이유별로 묶되 선택한 체결은 원래 위치와 이유를 보여준다.
- 100회 체결의 단일 종목 집계, 비용·실현손익, 비교 누락, 미국 현지 날짜, 같은 날 재진입 전체 표시, 원본 보존을 포함한 전체 테스트 102개와 빌드·문법 검사를 통과했다. SQLite 백업 후 로컬 앱에 반영했다.
- 실행 화면에서 종목별 카드와 체결별 복기 제거, 하루 전체 차트, 실제 매매 표식 위의 판단 이유 툴팁 표시를 확인했다.

## API 1분봉과 5초 관측 차트

- 기존 분당 마지막 관측 선차트를 토스 API 1분봉 OHLCV·거래량 차트로 보완했다. 공식 문서의 봉 종료 시각·최대 200봉·nextBefore·수정주가 미적용 규칙을 확인했다.
- 기존 5초 보유 시세를 같은 5초 구간별로 보관해 분 단위 덮어쓰기를 해제했다. 저장 관측가 겹쳐 보기로 API 캔들과 구분하며 기존 과거 분 단위 자료를 5초 자료로 생성하지 않는다.
- 팝업에 사용자별 캐시·동일 요청 공유·페이지 상한·실패 시 저장 자료 대체를 적용했다. 기존 유효 토큰과 공통 대기열만 재사용하고 원장·전략·매매에는 쓰지 않는다.
- 전체 테스트 107개 통과: 페이지 경계·통화/OHLC 검증·0거래량·요청 공유/캐시/사용자 격리·API 오류·미래 봉·미국 DST 날짜·5초 관측 보존을 확인했다. 빌드와 문법 검사 후 SQLite 백업을 완료했다.
- 실제 국내·미국장 팝업에서 API 분봉·통화·거래량·관측가 겹침·판단 툴팁을 확인했다. 조회 상한과 누락 거래량 검증을 보완해 전체 테스트 108개를 통과했다.
