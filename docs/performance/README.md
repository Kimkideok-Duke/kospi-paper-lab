## 매일 기록할 내용

체결 당시 왜 진입·청산했는지 종목별로 종합한다. 같은 종목 100회 부분 체결은 100개 독립 판단으로 간주하지 않는다. 전체 체결은 날짜·시장별 CSV로 제공하되 사용자 ID·주문 ID·인증·계좌 식별값은 제외한다. 공개 범위는 사용자가 게시를 요청한 **소유자 모의계좌 거래와 성과**다. 실계좌와 다른 사용자의 원장은 읽거나 공개하지 않는다.

복기는 문제, 근거, 대안, 실제 수정 이력, 적용 뒤 관측 결과를 연결한다. `reviews[date].adaptive`의 변경/유지/예약과 `dailyPolicy.applied`의 실제 적용은 다르다. 적용 기록은 `reviewDate`로 원래 복기 날짜를 찾는다. 사용자 요청에 따른 코드·설정 변경은 자동 복기 변경과 구분하고 Git 커밋, `versions` 시각과 일치시킨다. 변경하지 않았다면 이유를 적는다. 단순히 손실이 났다는 이유로 새 전략을 만들어 실행하는 작업은 아니다.

수정 뒤 결과는 적용 전후 **관측 구간·체결수·완결 매매수·보유분·비용·평가 기준·표본 한계**를 명시한다. 변경 시점 이후 체결의 실현손익은 기존 보유분 매도까지 포함하므로 버전 전체 수익률이나 인과 효과가 아니다. 같은 조건의 재현·비교가 없으면 개선을 입증했다고 쓰지 않는다. 사후 5분 관측가 비교는 가상의 체결 수익이 아니다. 적용 후 데이터가 없으면 다음 거래일부터 추적한다.

## 평가 산정 기준

- 국내: 시간외장 종료 후 확인한 토스 KRX·NXT 통합 일봉 종가. 미국: 정규장 일봉 종가와 마감 이전 저장 환율. 시장 캘린더와 `reviewCloseAudits`를 확인한다.
- `status=complete`와 `valuationStatus=complete`가 모두 충족된 감사 평가액만 확정 종가 평가액으로 쓴다. 전 종목 가격만 확인되고 환율·과거 원장이 부족하면 미확정이다.
- 일간 평가손익은 해당 거래일 확정 평가액에서 직전 거래일 확정 평가액을 뺀다. 첫날은 최초 원금 1,000만 원을 기준으로 한다. 첫 저장 일봉의 시작 평가액은 이미 손익이 발생한 뒤일 수 있어 원금 대신 쓰지 않는다. 직전 확정 평가가 없으면 계산 보류한다.
- 누적 수익률은 `(확정 평가액 / 최초 원금 - 1) × 100`이다. 원금 변동이 발생하면 입출금과 수익률 산식을 별도로 검토한다.
- 실현손익은 저장된 매도 체결의 원화 실현손익 합계다. 평가손익과 합산하지 않는다. 수수료·세금·환전 비용은 이미 원장 정산에 포함되어 중복 차감하지 않는다. 슬리피지는 체결가격에 반영되어 별도 이중 차감하지 않는다.
- 과거 비용 상세 미기록은 0원 비용의 증거가 아니다. 미기록 건수와 당시 모델 한계를 명시한다. 비용 모델 변경 전후를 같은 조건의 실적이라고 보지 않는다.
- 휴장은 저장된 해당 날짜 시장 캘린더 등 근거가 있을 때만 표시한다. 무거래·휴장·자료 미수집·미확정을 구분한다. 휴장일에 이전 평가를 새 종가나 0% 수익으로 만들지 않는다.
- 원래 원장·복기 보고서·전략·서버는 변경하지 않는다. DB는 읽기 전용으로 소유자 테이블 `campaign`, `us_campaign`의 `state`만 읽는다. 수동 거래 실행이나 실거래 모듈 활성화는 하지 않는다.

## 공개와 재시도
