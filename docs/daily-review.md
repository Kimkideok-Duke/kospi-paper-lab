# 일별 매매 복기와 다음 거래일 전략 보완

2026-11-26 사용자는 마감 후 거래 이유·결과·더 나은 선택을 종합한 복기, 네비게이션의 달력 메뉴와 날짜별 손익, 복기에 따른 매일의 전략 보완을 요청했다. `paper-v5-daily-review`에 적용했다. 실제 주문은 비활성 상태를 유지한다.

## 달력과 상세 보고서

국내장은 `/reviews`, 미국장은 `/us/reviews`의 **매매 복기** 메뉴를 사용한다. 한국 거래일과 미국 뉴욕 현지 거래일을 구분한다. 달력의 금액은 전 기록일 대비 **평가손익**이며 보유 평가 변화를 포함한다. 상세 화면의 **실현손익**은 해당 거래일 매도 체결에 저장된 순손익 합계다. 두 값을 같은 수익으로 해석하지 않는다. 체결 수는 부분 체결을 각각 포함한다.

보고서는 당시 저장된 거래 이유, 전략 버전, 주문 기준가·지정 범위, 실제 비용과 실현손익, 매도 이유별 결과, 분석 성공·실패 기록, 사후 대안과 자료 한계, 다음 전략 보완안을 포함한다. 저장된 기록을 규칙으로 종합한 보고서이며 LLM의 자유형 투자 판단이나 수익이 입증된 최적화가 아니다.

기능 추가 이전에 끝난 거래일은 남아 있는 기록으로 소급 복기한다. 당시 시세 경로·주문 정보가 없으면 이를 없다고 표시하고 가격이나 매매 이유를 만들어내지 않는다. 완성된 보고서는 재시작·재조회로 덮어쓰지 않는다.

## 자동 작성 시각과 장애 처리

- 서버의 기존 1분 감시에서 시장별 장 운영 일정을 보존한다. 국내장은 연속매매 종료가 아닌 정규장 전체 종료 시각, 미국장은 실제 정규장 종료 시각(조기 폐장 포함)을 사용한다.
- 전체 장 마감 후 최소 1분의 여유를 두고, 다음 감시에서 보고서를 작성한다. 그 전에 최근 정규장 마감 시세로 평가를 재점검한다. 이 조회는 평가 전용이며 주문·체결을 만들지 않는다.
- 마감 시세가 없거나 API가 실패하면 마지막 관측 평가가 포함된 부분 자료임을 명시한다. PC가 꺼져 있던 날은 다음 기동 시 남아 있는 기록으로 작성하며, 과거 시세나 거래를 소급 생성하지 않는다.
- API를 연결 해제한 경우에도 보존된 장 일정과 거래가 있으면 복기를 작성한다. 해당 날짜의 정상 장 일정도 없고 아직 같은 거래일이면 마감을 추정하지 않고 기다린다.

## 대안의 계산과 한계

보유 종목·당일 거래한 종목(최대 30개), 분석 상위 후보 일부의 실제 관측 시세를 분 단위로 저장한다. 대량 종목별 API를 새로 호출하지 않고 기존 시세 조회를 활용하며, 매도 후 당일 종목은 기존 배치 조회에 추가한다. 시장별 하루 최대 15,000개 시세 포인트, 최근 3개 기록일 상세 자료를 유지하고 완성 보고서는 원장에 남긴다.

체결 5~7분 후의 실제 관측값이 있을 때만 ‘5분 기다렸을 때’의 가격 차이를 같은 수량으로 계산한다. 미국장은 체결 당시 환율을 고정한다. 이는 수수료·미끄러짐·호가 잔량·새로운 진입 조건·실제 체결 가능성을 재현한 대안 수익이 아니라 **사후 가격 차이 참고액**이다. 유리한 값이 있었다고 당시 예측하거나 같은 수량을 체결할 수 있었다고 결론 내리지 않는다.

## 실제로 적용되는 일별 보완

보고서는 매일 보완 여부를 판단하지만 매일 반드시 수치를 바꾸지는 않는다. 근거 부족·무거래·유지 조건도 보고서에 기록한다. 바뀐 값은 해당 사용자·시장에만 저장하고, 다음 거래일의 실제 거래소 일정이 확인된 개장 15분 전 이후에 한 번 적용한다. 주말이나 휴장일을 임의의 다음 거래일로 계산하지 않는다. 적용 시 대기 매수를 취소하고 전략 버전·근거 보고서·변경 전후 값을 기록한다. 과거 체결·현금·보유분·비용 가정은 바꾸지 않는다.

| 항목 | 변경 근거 | 회당 변화 | 범위 |
|---|---|---|---|
| 신규 매수의 최소 분봉 상승세 | 최근 최대 20회 완결 매매가 5회 이상·2개 거래일 이상이고 당일 새 완결 매매가 있음. 합산 순손실이며 손실 비율 60% 이상 | +0.05%p 강화 | 0.15~0.60% |
| 최대 호가 간격 | 최근 비용 기록이 있는 매수 체결 중 주문 5건 이상·2개 거래일 이상, 당일 새 매수 있음. 불리한 체결 가격 차이가 거래금액의 0.15% 초과 | −0.05%p 축소 | 0.25~0.65% |

완결 매매는 최초 매수부터 수량이 모두 매도될 때까지 한 묶음으로 계산한다. 같은 주문의 부분 체결 여러 개를 여러 독립 전략 표본으로 취급하지 않는다. 기존 가용 현금 내 매수·비중 상한 없음·최대 5종목·−2.5% 손절·+5% 익절·10분 분석·1분 감시와 뉴스·공시 정책은 유지한다. 이번 자동 보완은 진입 기준과 호가 간격에 한정하며 수익 개선을 보장하지 않는다. 거래 비용을 낮아 보이도록 가정치를 바꾸지 않는다.

## 데이터 경계와 검증

복기·관측자료·변경 예약·적용 이력은 기존 사용자별 모의 원장 안에 저장한다. `GET /api/reviews`, `/api/us/reviews`는 현재 로그인한 사용자의 달력만 반환하고 `?date=YYYY-MM-DD`는 그 사용자의 상세 보고서만 반환한다. 사용자 ID를 헤더나 쿼리로 바꿔 다른 원장을 읽을 수 없다. 개인 보고서와 거래 데이터는 GitHub에 게시하지 않는다.

테스트는 한국 마감·뉴욕 거래일·조기 폐장·보고서 중복 방지·기록 보존·사후 가격 비교·부분 체결 표본·유효 거래일 적용·실제 매수 후보 필터의 변화·사용자별 접근 차단을 확인한다. 실제 주문 API를 사용하지 않는다.

## 전체 종목 종가 별도 확인 (2026-11-26)

사용자는 마감 시세 미확인에 따른 부분 평가를 보완하고 전체 평가 대상의 종가를 별도로 확인하도록 요청했다. 국내 기준은 사용자가 선택한 **토스 KRX·NXT 통합 일봉 종가(시간외장 포함)**이며 KRX 15:30 공식 종가라고 표시하지 않는다. 미국은 정규장 공식 일봉 종가다. 공식 FAQ의 데이터 범위를 확인하고 일봉을 `adjusted=false`, 해당 날짜·통화 일치 조건으로 조회한다.

- `closing-audit.mjs`는 해당 거래일 보유 잔량과 당일 거래한 모든 종목을 모은다. 기존 복기 관측의 30종목 제한을 적용하지 않는다. 거래소 전체 종목 목록이 아니라 해당 사용자 원장의 평가·복기 관련 종목 전체다.
- 국내는 거래일별 실제 통합 시간외장 종료+1분, 미국은 실제 정규장 종료+1분부터 조회한다. 휴장·조기 폐장·DST는 거래소 캘린더에 따른다. 시간외장 종료가 20:00이면 국내 확인 시작은 20:01이다.
- 현재가를 마감 시세로 간주하지 않는다. 종목별 일봉의 날짜·통화·유효한 종가를 확인한다. 조회 기회가 마감 후 15분으로 제한되지 않으며 서버 재시작 후 과거 거래일도 별도로 확인한다.
- 회당 최대 8개 요청과 공통 그룹별 제한 대기열을 사용한다. 완료 종목은 재호출하지 않고 실패·누락 종목만 1분부터 최대 1시간 백오프로 다시 확인한다. 전체가 확인돼야 완료다.
- 상태·종가·조회 시각·자료 출처는 사용자별 `reviewCloseAudits`에 보관하고 보고서에서 전체 N/N 및 종목별 현황을 표시한다. 가격과 거래 내역을 GitHub에 올리지 않는다.
- 원래 보고서·실제 모의 체결·현금·보유분·일별 전략 보완은 덮어쓰지 않는다. API가 반환하는 복기·달력 화면에서 확인 종가 기준 평가를 별도로 보완한다. 당시 현금·수량은 마감 시각 이전 거래의 정산 금액으로 재구성한다. 미국은 마감 이전 마지막 저장 환율과 시각을 명시하며 해당 환율 자료가 없으면 가격 확인과 원화 평가 완료를 구분한다. 직전 거래일의 확인 평가가 없으면 당일 평가손익을 임의 계산하지 않는다.
- 기존 화면 보고서는 종가 확인 진행/완료 버전에 따라 캐시를 갱신한다. 다른 자료 한계 문구는 유지한다.
