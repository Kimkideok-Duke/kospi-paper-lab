# 2026-11-28 전략 연구: 후보 선정의 표본과 기준선 검사를 보완

## 이번 결정

운영 매매 규칙은 유지했다. 국내 자동 복기의 진입 상승세0.15%→0.20%는 아직 예약 상태이며 실제 적용으로 취급하지 않았다. 손절7%·익절5%·종목15%/총투자60%·1회 위험0.35%·일손실1% 신규매수 중지 기준도 바꾸지 않았다. 이번 수정은 오프라인 연구의 잘못된 후보 통과와 호가 해석을 막는 검사이며 운영 전략의 성과 개선 적용이 아니다.

## 이전 가설과 수정 후 자료

11월27일에는 국내13회·미국2회의 완결 매매가 추가됐다. 손절 폭 변경 뒤 국내 당일 체결은 없었고 미국에서는 손절 청산 표본이 없었다. 이전 보유분의 익절이 섞인 당일 손익을 새 손절 기준의 성과로 해석하지 않았다. 당시 관측은 [11월27일 공개 복기](../performance/2026-11-27.md)에 별도로 기록했다.

실제 진입 주문이 생성된 관측에 한정하면 국내14개·미국3개가 있었다. 독립3주 가상 비교에서 국내는 즉시 방식14개·눌림9개·분할9개가3주를 채웠고 세 방식 모두 채운 관측은8개였다. 미국은3개 모두 세 방식에서3주를 채웠다. 이 비교는 실제 주문 수량·현금 예약·대기 순번을 재현한 성과가 아니며 같은 종목 반복 관측도 섞인다. 눌림 방식이 항상 유리하다는 결론을 보류하고 미체결 표본을 함께 유지했다.

## 확인1: 부분 매도 주문 수가 완결 매매 표본을 대신하고 있었다

기존 연구 후보 검사는 검증 구간의 매도 주문5개를 표본 조건으로 사용했다. 한 보유분의 부분 매도만 쌓여도 이 조건을 통과할 수 있었다. 또한 양의 검증 수익과 절대 낙폭 한도만 검사해 동일 자료의 기준선보다 나은지와 비용 악화를 확인하지 않았다.

학습·검증 각각 완결 매매5회·청산 거래일2일을 요구하도록 고쳤다. 기존 완결 매매 계산을 재사용하며 잘못된 수량 연결과 실현손익 미기록은 제외한다. 검증 수익은 명시한 기준선보다 높아야 하고 최대 낙폭·명시 비용·가격 반영 슬리피지가 악화되면 기각한다. 각 후보의 기각 이유도 저장한다. 선택한 구간에 스냅샷이 없으면0% 실적으로 채우지 않고 해당 구간과 탐색을 blocked로 표시한다. 합성 자료에서 매도 주문100개·완결 매매0개인 경우와 단일 거래일·비용/낙폭 악화·지표 누락·빈 평가 구간을 기각하는 것을 확인했다.

코드 기본 기준선은 진입 상승세0.15%·호가 간격0.20%·패턴 미사용이다. 이번 조회의 적용된 정책과 일치하며 예약된0.20% 상승세는 사용하지 않았다. 이후 실제 정책이 바뀌면 실행 인자로 기준선을 명시해야 한다. 후보가 있을 때만 별도 평가 구간의 후보와 기준선을 계산하며 자동 운영 승격은 계속하지 않는다.

## 확인2: 호가 배열 순서가 진입 판단을 바꾸고 있었다

기존 재현은 배열 첫 호가로 간격을 계산했고 실제 모의 체결 모형은 호가를 가격순으로 정렬했다. 합성 자료에서 같은 호가를 다른 순서로 넣자 적격 판단이 달라지는 것을 재현했다. 숫자가 아닌 가격도 기존 archive 검사에서 거절되지 않았다.

연구용 호가를 정규화해 간격과 체결 모형이 같은 최우선 가격을 사용하도록 고쳤다. 잘못된 가격·잔량·중복 가격 단계는 재현을 중단한다. 잔량0과 통합 교차 호가에서는 현 모형이 신규 체결을 만들 수 없으므로 후보를 적격으로 세지 않는다. 원본 배열을 변경하지 않는 것과 두 거래일의 완결 매매·비용 지표를 합성 자료로 검증했다.

슬리피지는 부호가 있는 가격 효과다. 유리한 체결에서 음수가 나오는 검증을 포함했고, 체결가격에 이미 반영된 슬리피지를 순수익에서 다시 차감하지 않았다. 이는 비용 개선을 실측했다는 뜻이 아니다.

## 확인3: 원시 분봉과 당시 시점의 재현 자료는 구분해야 한다

지수 일봉 수집을 갱신해5월4일~11월27일141거래일을 확인했다. `research/run.mjs`는 여전히 `blocked`, 자동 적용은 false다. 전체 전략의 실제 조건 탐색은0회이며 검증된 새 수익률·최적 알고리즘을 선정하지 않았다. 이번 합성 검증은 실제 코스피 전략 실험으로 세지 않는다.

분봉 수집은 별도 고정 범위5월1일~11월26일로 진행 중이다. 표본 점검 시2,485개 대상 중115종목의 API 순회가 끝났고 원시 봉 약831만 개가 저장돼 있었다. 이 숫자는 전체 수집 완료나 경계 중복 제거 후의 전체 봉 수가 아니다.

완료 종목3개와 현재 종목의 저장 완료 페이지를 점검했다. 완료 표본3개는 각각140거래일을 포함했고 잘못된 봉·페이지 연결·충돌 중복이 없었다. 현재 종목은 아직 과거 방향 수집 중이므로 그 시점의 미관측42거래일을 수집 실패로 세지 않았다. 현재 전체 종목 목록과 당시 상장폐지 포함 목록의 차이, 과거 호가·후보·기사 버전은 여전히 별도 확보·검증이 필요하다.

전체 회귀 검증 중 수집 재개 검사가 한 번 실패해 원인을 확인했다. 최종 체크포인트 저장이 끝나기 전에 paused를 노출해 곧바로 재개하면409가 날 수 있었다. 저장과 실행 슬롯 해제가 끝나기 전에는 진행 중 상태를 유지하도록 보완했다. 이 호스트 변경은 실행 중 수집을 끊지 않도록 현재 프로세스를 재시작하지 않았으며 다음 정상 재시작 때 반영된다.

11월27일 웹 자료만 추가 수집하도록 날짜 선택을 넣어 이전 캐시를 다시 돌리지 않았다. DART는339/342건으로3건 부족해 partial, 뉴스는3페이지60건의 부분 목록이다. 선정 기사2건의 발표 메타데이터와 공시1건의 본문 링크·해시를 추가 확인했다. 두 기사의 발표 시각은23:08:08·23:36:09, 공시는18:41이며 모두 한국 정규장 이후다. 당시 원문 버전의 동일성도 미확인이므로 정규장 판단 근거로 소급하지 않았다.

커뮤니티 현재 목록31건을 확인했으나 당시 원문 검증은 미완료다. X는 조사 목록4개와 실제 원문0건 상태를 유지하며 새 원문을 받았다고 소개하지 않는다. 소셜 자료를 운영 매매 기준으로 승격하지 않았다.

## 검증·적용 범위와 후속 관찰

키 없는 전체 테스트150개 통과. 새 연구 검증6개를 포함하며 기준선·표본·호가·부호 있는 슬리피지와 원시 페이지 중복/충돌을 검사했다. 실제 전략 조합 탐색과 새 정책의 독립 전진 검증은 수행하지 못했다. 테스트 통과를 수익 검증으로 해석하지 않는다.

연구 CLI·검사·수집 상태 표시·테스트와 문서를 변경했다. 연구 CLI 변경은 다음 실행부터 사용되며 호스트의 저장 완료 상태 보완은 다음 정상 재시작 반영을 기다린다. 실행 중인 수집을 끊지 않도록 운영 서버를 재시작하지 않았고 운영 모델 버전과 기존 원장도 보존했다. 매매 실행·토큰 발급·실제 주문 호출은 하지 않았다. 다음 실행에서는 완료된 분봉 범위와 날짜별 원문 증거를 확인하고, 자료가 준비된 범위에서 명시한 기준선과의 비교를 진행한다.
