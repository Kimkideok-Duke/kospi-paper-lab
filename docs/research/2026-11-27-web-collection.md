# 2026-11-27 웹 자료 수집 결과

2026년5월 이후 코스피 백테스트를 위해 날짜별 웹 목록과 검증 가능한 원문 근거를 수집했다. 대상은 마지막 완료 거래일인11월26일까지140거래일이다.

| 자료 | 저장·확인 결과 | 범위와 한계 |
|---|---:|---|
| 코스피 일봉 | 140거래일 | 5월4일~11월26일 |
| DART 코스피 공시 목록 | 26,132건 | 공식 표시 총건수 일치77일, 나머지63일은 일부 누락 |
| 금융뉴스 목록 | 960건 | 일부 날짜의 첫3페이지, 전체 기사 아카이브는 미확보 |
| 선정 공시 문서 | 119건 | 본문 링크·해시·짧은 발췌 확인, 원문 전체를 공개 저장소에 재배포하지 않음 |
| 기사 발표 메타데이터 표본 | 1건 | SBS 5월4일11:31:08 기사, 당시 원문 버전은 미확인 |
| 커뮤니티 목록 | 31건 | 팍스넷 현재 목록, 과거 반응으로 소급하지 않음 |
| X 원문 게시물 | 0건 | 트럼프·머스크 프로필403, 계정 조사 목록만 생성 |

금융뉴스 목록의 일부 기사에는 원래 기사 날짜보다 뒤인 수정 시각이 표시됐다. 이 자료를 당일 발표 기사로 간주하지 않았다. 기사 페이지의 원래 발표 메타데이터, 현재 본문 버전의 확인 상태를 따로 저장했다. 일부 뉴스 원문 요청은 연결 실패·시간 초과로 중단했으며 대체 언론사 목록도 시간 초과였다. 전체 수집으로 표시하지 않았다.

DART 목록은 API 인증키 없이 공개 날짜 검색 화면에서 수집했다. 접수시각은 분 정밀도여서 해당 분이 끝난 뒤 가용한 것으로 처리한다. 본문 버전의 당시 동일성은 추가 확인이 필요하다.

X 계정 후보는 realDonaldTrump, elonmusk, KobeissiLetter와 본인 확인 대기 DeItaone이다. 공식 출처와 프로필 접근 상태를 기록했다. 원문 게시 시각·수정 이력·본인 여부를 확인한 게시물만 과거 연구에 포함한다. 사용자는 조회용 계정이 필요하면 요청하도록 허용했다. 현재 브라우저 제어 연결이 없어 공식 로그인 인계를 진행하지 못했다.

커뮤니티 글은 제목·출처·게시 및 수집 시각만 저장했다. 작성자 식별값은 수집하지 않았다. 현재 원문 버전을 과거 시점의 글로 사용하지 않으며 복사 글과 나중에 늘어난 추천·조회수를 구분한다. 정보는 투자자 관심·분위기 연구 자료로 취급하며 사실 주장은 뉴스·공시와 교차 확인한다.

원자료와 실패 상태는 outputs/research/web-history 및 outputs/research/social에 보존했다. Git에는 수집 코드·검증·이 문서만 포함한다. 백테스트에는 당시 구성종목·분봉·호가·후보 자료가 추가로 필요하며, 이번 수집 결과로 전체 전략 수익률이나 최적화를 완료했다고 판단하지 않는다.

테스트138개 통과. 날짜별 목록 파싱, 수정 날짜 구분, 발표 시각 메타데이터, 커뮤니티 중복 제거, 미래 정보 제외를 검증했다. 운영 모의 원장과 매매 규칙은 변경하지 않았다.
