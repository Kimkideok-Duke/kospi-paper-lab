# 익명 모의 거래 관람

2026-11-27 요청으로 PC 서버에 별도 공개 화면을 추가했다. 원금·평가자산·누적 평가손익·현금, 보유 종목과 최근 100개 모의 체결, 최근 240개 평가 관측값만 제공한다. 국내/미국 시장을 전환한다. 소유자 모의계좌만 공개하며 실계좌·다른 사용자는 제외한다.

## 공개·비공개 경계

- `server/public-watch.mjs`는 소유자 DB의 state를 읽고 허용된 필드만 새 객체로 만든다. 사용자 ID·이름·이메일·API 키·토큰·계좌 정보·오류·서버 상태·매매 사유·전략·주문 ID·운영자 이메일·원본 복기·분봉 원본은 전달하지 않는다. 종목 이름/코드와 매매 수치·시각만 공개한다.
- 화면은 별도 HTML/JS/CSS를 사용하며 외부 리소스·프로필·GitHub·관리 페이지 링크가 없다. CSP, no-store, no-referrer, noindex 헤더를 적용한다. 제3자의 공개 내용 복사까지 차단하는 기능은 아니다.
- `server/watch-gateway.mjs`는 8767 루프백 포트에서 `/watch`, `/watch/`, 두 화면 자산, `/watch/join`, `/watch/data`만 전달한다. 로그인·설정·내부 API를 포함한 다른 경로는 404다. 관리 세션과 인증 헤더는 전달하지 않는다. 루트는 `/watch`로 이동한다. URL로 계좌·사용자를 선택할 수 없다.
- 로그인 대신 무작위 임시 관람 쿠키만 발급한다. 관람 세션은 RAM에만 보관하며 내부 API 권한은 없다. 가입·비밀번호·개인정보 입력이 없고 실제 주문과 쓰기 API는 연결하지 않는다.

## 부하와 접속 제한

- 최대 20개 활성 브라우저 세션이다. 여러 탭은 같은 쿠키를 공유하고 다른 브라우저는 별도 접속으로 센다. 사람을 식별하거나 고의로 복제된 쿠키를 사람별로 구분하지 않는다.
- 화면은 30초마다 갱신하고 숨겨진 탭은 중단한다. 90초 동안 요청이 없는 세션은 만료돼 자리를 반환한다. 초과 접속은 429와 안내를 반환하며 재접속 시 다시 상한을 검사한다.
- 세션별 1초 미만 반복 조회를 차단한다. 모든 관람자가 15초 캐시와 진행 중 조회를 공유한다. 관람자의 요청은 토스 API를 호출하지 않는다.
- 관람 서버와 프록시는 평균 초당 20회·순간 40회로 제한한다. 프록시는 진행 중 요청 8개·연결 64개·10초 타임아웃을 적용한다. 입장도 초당 1개·순간 20개로 제한한다. 보수적인 초기 설정이며 부하 시험으로 보장한 최대 처리량은 아니다.

## Windows 운영

브라우저 호환 보완(2026-11-27): 공개 경로의 HEAD 확인을 지원하고 본문은 보내지 않는다. 읽기 요청의 Origin은 입장 권한으로 사용하지 않으며 POST 입장은 기존 동일 출처 검사를 유지한다. 관람 전용 게이트웨이의 익명 허용 응답에만 프레임 차단 헤더를 제거해 내장 브라우저에서 표시할 수 있게 했다. 관리 페이지의 인증·프레임 차단 및 경로 허용 목록은 유지한다. 외부 HTTPS의 HEAD/GET·화면 자산·익명 입장/데이터 200, 내부 경로 404를 확인했다. 브라우저 제어 연결을 사용할 수 없어 실제 내장 브라우저 화면은 직접 검증하지 못했다.

기존 `node scripts/local.mjs` 서버를 새 코드로 재시작하고 `%LOCALAPPDATA%/MarketLabHost/cloudflared.exe`가 준비된 PC에서 `node scripts/watch-host.mjs`를 실행한다. 이 스크립트는 별도 관람 프록시와 임시 HTTPS 터널을 실행하고 현재 주소를 비공개 운영 폴더의 `watch-url.txt`에 기록한다. 기존 관리용 터널과 주소는 유지한다. 자동 시작이 필요하면 운영 supervisor에 관람 호스트를 연결해야 한다.

현재 배포 상태: 2026-11-27 사용자의 외부 HTTPS 접속 재요청 후 운영 DB를 백업하고 서버를 재시작했다. 관람 전용 프록시·별도 터널을 실행하고 기존 supervisor의 다음 자동 시작에도 연결했다. 외부 HTTPS에서 화면·익명 입장·국내/미국 공개 데이터를 HTTP 200으로 확인했다. 같은 호스트의 설정·로그인·계정/국내/미국 내부 API 경로는 404로 차단됨을 확인했다. 전체 127개 테스트와 빌드 검증은 앞선 구현 때 통과했다.

도메인/Cloudflare 계정을 연결하지 않은 Quick Tunnel 주소는 재생성 시 바뀔 수 있다. PC 종료·절전·인터넷 단절 중에는 접속이 중단된다. pid·로그·URL은 운영 폴더에만 보관한다.
