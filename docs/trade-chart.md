# 거래 차트 팝업

국내·미국장 대시보드의 최근 거래 또는 거래내역에서 거래 행/종목의 **차트** 버튼을 클릭한다. 팝업은 종목의 저장 가격과 같은 매매 묶음의 실제 모의 매수·매도 체결을 함께 표시한다. 매수는 빨간 위쪽 삼각형, 매도는 파란 아래쪽 삼각형이며 선택한 체결을 원으로 강조한다. 차트 표식 또는 하단 체결 목록에서 다른 체결을 선택하면 가격·수량·시각·이유·매도 실현손익·미국장 환율 상세가 바뀐다. 닫기·Escape·팝업 바깥 클릭으로 닫는다. 버튼은 키보드로도 사용할 수 있다.

`GET /api/trade-chart?id=<tradeId>`, `GET /api/us/trade-chart?id=<tradeId>`는 현재 세션 사용자의 시장별 저장 원장만 읽는다. 다른 사용자의 ID나 헤더로 원장을 선택할 수 없고 외부 시세 호출·주문·전략 변경·DB 쓰기를 하지 않는다. 같은 종목이라도 전량 매도 후 재진입한 거래는 다른 묶음이다. 매수 기록이 없는 이전 매도는 해당 체결만 표시한다.

차트 가격은 기존 복기 관측가, 보관된 진입 전 1분봉 종가, 새로 보존하는 `tradeCharts`를 사용한다. OHLC 봉이나 기록되지 않은 과거 가격을 생성하지 않는다. 실제 체결가는 가격선에 합쳐 넣지 않고 별도 표식으로 표시한다. 3분 초과 가격 공백은 선으로 연결하지 않고 저장 경로가 부족하면 확인된 체결점만 표시한다. 미국장 세로축은 달러이며 원화 체결가로 대체하지 않는다. 모든 시각은 한국 시간이다.

기존 `recordReviewEvidence`에서 사용 중인 시세를 재사용해 매매 묶음별로 분당 한 관측을 보관하고, 전량 매도 후 30분까지만 추가한다. 외부 API를 늘리지 않는다. 장기 보유는 3,000개를 넘으면 구간을 간추리고 이를 화면에 명시한다. 이 보관 자료는 복기 상세의 최근 3일 제한과 분리되어 이후에도 체결 차트를 볼 수 있다. 과거 거래에 없던 가격 경로는 소급 생성하지 않는다. 기존 원장의 현금·보유·가격·매매 이유·실현손익은 바꾸지 않는다.

2026-11-26 표시 개선: 3분 초과 공백은 실선 대신 회색 점선 참고 연결로 표시하고 미관측 구간임을 범례·설명에서 구분한다. 점선상의 가격을 관측 데이터나 툴팁 값으로 생성하지 않는다. 24건 초과 체결은 같은 방향의 5분 구간별 수량 가중평균 표식과 건수로 묶으며, 선택한 체결은 정확한 원래 시각·가격에 별도로 그린다. 하단 목록은 모든 원래 체결을 유지한다.
