# 거래 차트 팝업

국내·미국장 거래 행/차트 버튼과 종목별 복기의 하루 매매 차트 버튼에서 연다. 토스 API 1분봉(시가·고가·저가·종가)과 거래량을 기본으로 표시하고 실제 모의 체결을 별도 표식으로 표시한다. 저장 관측가 겹쳐 보기를 켜면 기존 자료와 앞으로 보관하는 5초 관측을 함께 확인한다. API 조회 실패·연결 없음·유효 토큰 없음은 저장 자료로 대체하고 이를 표시한다. 과거에 저장하지 않은 5초 시세는 소급 생성하지 않는다.

## 자료 조회와 표시

- GET /api/trade-chart?id=<tradeId> 및 미국장 경로는 로그인한 사용자 원장에서 거래를 먼저 검증한다. date=YYYY-MM-DD는 해당 시장 거래일의 같은 종목 하루 전체 체결을 선택하며, 날짜가 선택 거래와 다르면 조회하지 않는다. 날짜가 없으면 최초 매수부터 전량 매도까지의 매매 묶음이다.
- server/chart-candles.mjs는 공식 candles API의 interval=1m, adjusted=false, count=200과 제공된 nextBefore로 과거 봉을 조회한다. 중복 경계를 제거하고 날짜 범위·통화·OHLC 범위·거래량을 검증한다. 미래의 봉은 표시하지 않는다. 12페이지 상한이나 부분 실패를 완료로 표시하지 않는다.
- 봉의 timestamp는 종료 시각이다. 실제 체결은 원래 시각·가격으로 별도 표시한다. 시간축은 한국 시간, 미국 가격은 USD다. 미국 1분봉은 일부 거래소 기준이며 NBBO/전 시장 체결이 아니다. 국내 캔들은 KRX·NXT 통합 자료다. 진행 중 자료나 늦게 보고된 미국 체결은 변경될 수 있다.
- 1분봉의 시가·고가·저가·종가·거래량은 API가 제공한 실제 집계다. 체결 없는 분의 국내 0거래량 봉은 유지하고, 미국에서 제공되지 않은 분의 봉은 생성하지 않는다.

## 5초 관측 보존

기존 보유 감시에서 받은 시세를 재사용한다. q.time(실제 시세 시각)을 보존하며 같은 5초 구간만 마지막 관측으로 합친다. 같은 시각·오래된 시세·미래 시세는 중복 보관하지 않는다. 기존 분 단위 자료는 그대로 두고 5초 자료라고 소급 표시하지 않는다. 매매 묶음당 40,000개 초과 시 구간을 간추려 보존하며 화면에 알린다. 전량 매도 후 30분까지만 관측을 추가한다. 관측선의 3분 초과 공백은 회색 점선으로 구분한다.

## 매매 판단 툴팁

매수는 빨간 위쪽 삼각형, 매도는 파란 아래쪽 삼각형, 선택한 체결은 원으로 표시한다. 매매 표식 위에 마우스를 올리면 시각·방향·수량·가격·판단 이유를 보여준다. 24건 초과 체결은 같은 방향의 5분 구간별 수량 가중평균 표식과 건수로 묶고, 선택한 원래 체결은 별도 표시한다. 묶음의 이유는 이유별 체결 건수와 함께 표시한다. 하단 목록은 모든 원래 체결을 유지하며 키보드로 선택할 수 있다. 닫기·Escape·팝업 바깥 클릭으로 닫는다. 입력 문자는 HTML 이스케이프한다.

## 호출과 원장 경계

팝업의 분봉 조회는 기존 공통 MARKET_DATA_CHART 대기열을 사용한다. 사용자 DB별 메모리 캐시는 최대 32개 범위·60초이며, 진행 중 동일 요청을 공유한다. 부분 실패 캐시는 15초다. 5초 보유 감시에서 분봉을 반복 호출하지 않는다. 기존 유효 토큰만 사용하고 팝업 때문에 토큰을 발급/취소하거나 매매 원장을 잠그지 않는다. 토큰 만료 시 기존 감시의 갱신을 기다리고 저장 자료를 표시한다. 원장·현금·전략·실제 체결·원본 복기를 쓰지 않으며 실제 주문 API는 연결하지 않는다. 인증 없는 조회나 다른 사용자의 거래 ID로는 접근할 수 없다.

공식 근거(2026-11-26 확인): [REST OpenAPI](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json), [캔들 FAQ](https://openapi.tossinvest.com/openapi-docs/faq.md).

## 2026-11-26 기성 차트 엔진 적용

사용자가 실제 화면의 가독성과 직접 그리는 방식을 지적해 수동 Canvas 렌더러를 제거했다. TradingView Lightweight Charts 5.3.0의 공식 npm 배포 standalone ESM을 SRI 검증 후 web/vendor에 포함했다. Apache-2.0 LICENSE와 공식 태그의 NOTICE, 화면의 저작권 고지·TradingView 링크를 유지한다. 외부 스크립트 실행이나 CSP 완화 없이 로컬 자산으로 제공한다.

기성 엔진이 캔들·가격축·시간축·거래량·크로스헤어·휠 확대·드래그·터치 확대를 담당한다. 선택 체결 전 30분/후 90분을 기본 표시하고 전체 기간, 선택 매매 이동과 1/5/15분 집계를 제공한다. API의 1분봉 종료 시각은 실제 봉 시작 시각으로 변환하고 시가/고가/저가/종가·거래량을 집계한다. 없는 봉을 생성하지 않는다. 실제 매매 표식은 해당 봉의 시작 시각에 정렬하고, 가격은 실제 체결가(묶음은 수량 가중평균)를 사용한다. 툴팁·상세에는 원래 초 단위 시각과 가격을 보존한다. 같은 방향·같은 봉의 부분 체결을 묶고 선택 체결은 별도로 강조해 과도한 화살표와 중복 시간축을 방지한다.

완성된 외부 차트를 그대로 삽입하는 TradingView 위젯도 조사했다. 공식 위젯용 아시아 시장 목록에 KRX가 없고, 위젯에는 사용자 자료를 넣는 API가 없다. 국내·미국장과 사용자 체결 표시를 함께 유지하기 위해 차트 엔진을 사용한다. 원본 차트 버튼은 공개 종목 코드만 담은 TradingView 사이트를 새 탭으로 연다. 외부 차트에 개인 매매 시각·수량·가격·이유를 보내지 않는다. 원본 사이트의 제공 시세/지연/수정주가는 토스 자료와 다를 수 있다.
